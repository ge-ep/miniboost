# miniboost
<p><b>LPB-1 Clone circuit</b></p>
<p>A tiny THT clone of the LPB-1 circuit. Use at your own risk.</p>
<p><s>I'll update the repo when the design has been successfully tested.</s> V1 has been tested and confirmed working as expected.</p>
<p>I've uploaded a V1.1 which has the following minor changes:</p>
<ul><li>I've updated the text size on the silkscreen to make it easier to read</li>
    <li>I've added signal and ground markings on the input and output THTs so it's clear that the circle pad is ground.</li>
    <li>I've removed the 2N5088 text and added markings for the Collector, Base, and Emitter pins because half the fun with this circuit is trying out different flavours of transistor to see which one you like the best.</li></ul>
<p><b>Notes on this circuit:</b></p>
<p>Although I've only tested a few, most NPNs <i>should</i> work in this circuit. 2N5088 has the most gain, but that might not be what you're after, so try some others out and see.</p>
